# Windows 实用工具集

面向 Windows 10 / 11 的小工具集合，每个工具独立可用、无外部依赖、无网络请求。

```
tools/
  warm-overlay/     自定义夜间模式（护眼叠加）：截图不染色的屏幕降蓝光工具
```

## 工具

### 1) warm-overlay — 自定义夜间模式 / 护眼叠加

Win11 自带「夜间模式」失效时的备用方案。24 KB 单文件托盘程序。

**核心设计：截图和录屏不会被染色。** 主方案走显示器 gamma 曲线（与系统夜灯同一机制），在 GPU 输出端调色，帧缓冲像素不变，所以截出来永远是原始颜色；回退方案的全屏叠加窗口设置 `WDA_EXCLUDEFROMCAPTURE`，在截图/录屏 API 中完全不可见。

| 能力 | 说明 |
|---|---|
| 双引擎 | 色彩曲线（主）/ 叠加层（回退），可手动指定或自动选择 |
| 自动降级 | 检测到 HDR 或「自动管理颜色」时自动切到叠加层 |
| 快捷键 | `Ctrl+Alt+0` 开关、`Ctrl+Alt+↑/↓` 调强度、`Ctrl+Alt+W` 循环暖度 |
| 开机自启 | 写入 `HKCU\...\Run` |
| 曲线自愈 | 基线持久化 + 启动检测残留 + 退出还原 |

实测：开启与关闭护眼时，截图逐像素比对差异 **0.006 级（完全一致）**，而屏幕肉眼可见变暖。

细节见 [tools/warm-overlay/README.md](tools/warm-overlay/README.md)。

## 构建

各工具的构建方式见其 README。本项目统一**不提交编译产物**（`*.exe` 已在 `.gitignore` 中），请从源码构建。

`warm-overlay` 只需要 Windows 自带的 .NET Framework 4.x，无需 Visual Studio 或 .NET SDK：

```powershell
cd tools\warm-overlay
.\build.ps1
```

## 设计原则

- **单文件、零依赖** —— 不装运行时，不写注册表以外的东西（自启项除外）。
- **可复现构建** —— 源码 + 构建脚本齐全，任何人能编译出同样的程序。
- **副作用透明** —— 全局显示状态类工具必须说明「异常退出会怎样」，并提供自愈机制。
- **不留后台服务** —— 需要常驻的只有托盘进程本身。
